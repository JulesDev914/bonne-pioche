# 🎯 Bonne Pioche

**Générateur d'annonces pour Vinted & Leboncoin** — transforme une description rapide en une annonce qui se vend.

Tu décris ton article en quelques mots, l'app te génère :
- ✅ Un **titre** optimisé (max 60 caractères)
- ✅ Une **description** claire et honnête qui rassure l'acheteur
- ✅ **10 mots-clés** que les acheteurs tapent vraiment
- ✅ Un **conseil de prix** indicatif

## 🚀 Comment l'utiliser

1. Télécharge `bonne-pioche.html` (bouton **Download** ci-dessus)
2. Double-clique dessus → il s'ouvre dans ton navigateur
3. ⚙️ L'app utilise une IA locale via [LM Studio](https://lmstudio.ai) :
   - Installe LM Studio et télécharge un modèle (ex : `qwen3-4b`)
   - Démarre le serveur local (onglet Developer → Start, port 1234)
4. Remplis le formulaire, clique **Générer** → copie-colle ton annonce !

## 💡 Pourquoi Bonne Pioche ?

Les particuliers qui vendent souvent (vêtements, déco, électronique) perdent un temps fou à rédiger leurs annonces. Bonne Pioche fait le travail en quelques secondes, avec un ton simple et honnête qui convertit.
